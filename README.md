# rshot

一个轻量的 Windows 截图工具，使用 Rust 编写。支持冻屏框选、窗口自动锁定、画笔标注、置顶贴图、托盘常驻和全局热键。

**[下载最新版本 rshot.exe](https://github.com/idkwhatimdoing62/rshot/releases/latest/download/rshot.exe)**

## 功能

- **冻屏框选**：按热键冻结当前屏幕，拖出矩形选区。
- **窗口自动锁定**：移动鼠标时自动红框锁定光标下的窗口，单击进入编辑。
- **编辑工具栏**：选区确定后显示 `COPY / PEN / SELECT / PIN / UNDO / X` 浮动工具栏，操作不必记快捷键。
- **画笔标注**：点击 `PEN` 后用左键画红色重点笔，`Ctrl+Z` 撤销；也可按 `B` 开关画笔。
- **置顶贴图**：点击 `PIN` 把选区变成无边框、始终置顶的参考窗口。
- **重新选择**：点击 `SELECT` 或按 `R`，在同一张冻结画面上重新框选，不需要重新截图。
- **剪贴板输出**：同时提供位图和临时 PNG 文件，适配聊天软件、文档、终端和资源管理器。
- **多入口触发**：全局热键或双击托盘图标。
- **热键配置**：首次运行生成 YAML 配置文件，修改后重启生效。

## 使用

启动后程序常驻系统托盘。

| 阶段 | 操作 | 效果 |
|---|---|---|
| 待命 | `Alt+A` / 双击托盘 | 冻结鼠标所在屏幕 |
| 选择 | 移动鼠标 | 自动锁定光标下的窗口 |
| 选择 | 单击窗口 / 拖拽 | 确定窗口或手动选区，进入编辑 |
| 编辑 | 点击 `PEN` 后左键拖动 | 用红色画笔突出重点 |
| 编辑 | `Ctrl+Z` | 撤销上一笔 |
| 编辑 | 点击 `COPY` / `C` / 右键 | 复制结果到剪贴板并关闭 |
| 编辑 | 点击 `SELECT` / `R` | 保留冻结画面，重新框选 |
| 选择 / 编辑 | 点击 `PIN` / `P` | 将当前选区直接变成置顶贴图 |
| 贴图 | 左键拖动 | 移动贴图 |
| 贴图 | 点击右上角 `X` / 右键 / `Esc` | 关闭贴图 |
| 任意截图阶段 | `Esc` | 取消 |
| 待命 | `Alt+D` | 退出程序 |

贴图存在时不会重复开启第二个截图窗口；关闭贴图后可继续截图。

## 构建

需要 Windows 和 Rust 工具链。

```bash
cargo run
cargo build --release
```

Release 产物位于 `target\release\rshot.exe`，双击后在后台运行。

## 配置

首次运行生成：

```text
C:\Users\<用户>\AppData\Roaming\RShot\config\default-config.yml
```

```yaml
hotkey: Alt+A
quit: Alt+D
```

## 已知限制

- 仅支持 Windows。
- 目前一次只保留一张置顶贴图。
- 多显示器坐标逻辑已实现，但仍需要在更多缩放组合下验证。
- 剪贴板的文件格式会复用系统临时目录中的 `rshot.png`。
