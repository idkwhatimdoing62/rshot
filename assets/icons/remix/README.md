# Toolbar icon assets

These 20×20 alpha masks are generated from Remix Icon line-style SVGs on its 24×24 grid. They are embedded into the executable and colored by the native toolbar renderer; no font, SVG parser, or network access is required at runtime.

| rshot item | Remix Icon source |
| --- | --- |
| Pen | `brush-line` |
| Line | `subtract-line` |
| Arrow | `arrow-right-line` |
| Rectangle | `checkbox-blank-line` |
| Mosaic | `mosaic-fill` |
| Text | `text` |
| Color | `palette-line` |
| Undo | `arrow-go-back-line` |
| Copy | `file-copy-line` |
| OCR | `character-recognition-line` |
| Pin | `pushpin-line` |
| Reselect | `crop-line` |
| Close | `close-line` |
