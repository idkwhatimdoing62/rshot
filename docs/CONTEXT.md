# rshot

rshot 是一个 Windows 截图工具。本上下文统一描述截图、编辑、输出与置顶贴图相关的产品概念。

## Language

**截图操作**：
从接受截图热键开始，包含捕获尝试以及成功后的截图会话，直到失败清理、输出、转为置顶贴图或取消完成。
_Avoid_：截图任务、截图流程

**捕获尝试**：
截图操作开始后，为建立冻结图和遮罩窗口而进行的瞬时过程；它完整负责定位目标屏幕、暂时隐藏贴图、捕获冻结图并建立可用遮罩资源。贴图只在读取桌面像素期间隐藏，冻结图完成后立即恢复；只有全部步骤成功才产生截图会话，任一步失败都会释放临时资源并恢复贴图。
_Avoid_：截图会话、初始化

**截图会话**：
一次冻结画面的选择和编辑过程，聚合冻结图、遮罩窗口、选区和编辑状态；复制、OCR、转为置顶贴图、取消或失败恢复会结束该会话。
_Avoid_：截图流程、编辑窗口

**冻结图**：
截图入口成功后保留的原始屏幕图像；重新选择、OCR 和最终输出都以它为源。
_Avoid_：缓存截图、背景图

**截图输出**：
从冻结图和已确定的选区、标注生成最终图片；选区决定输出范围，选区外内容被裁切，没有选区时输出整张冻结图。复制和转为置顶贴图消费同一份截图输出。
_Avoid_：渲染结果、导出图

**剪贴板发布**：
把文字或图片内容交给 Windows 剪贴板，并报告实际可供外部程序消费的格式；图片允许部分格式发布成功。
_Avoid_：截图输出、复制流程

**受管临时产物**：
由 rshot 创建并负责保护、保留和回收的临时文件；被剪贴板引用期间不能删除，发布失败或超过保留期限且不再受保护时可以回收。
_Avoid_：缓存文件、任意临时文件

**文字识别**：
从冻结图或其选区的原始像素中提取文字的操作，不包含标注内容；OCR 是它的常用简称。
_Avoid_：截图转文字、文字提取
