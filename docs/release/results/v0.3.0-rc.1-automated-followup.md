# Windows automated follow-up: v0.3.0-rc.1

This record separates checks that can be reproduced without a human tester from checks that require a matching interactive Windows environment.

The captured environment is stored in `v0.3.0-rc.1-windows-environment.json`: Windows 11 x64, one 2560x1440 display at 100% system scale. It proves that mixed-DPI and multi-display scenarios were not exercised on this machine.
